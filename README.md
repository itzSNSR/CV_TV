# CineVault TV

A lightweight Android TV client inspired by CineVault. It provides a 10-foot user interface for Android TV and Google TV devices, with D-pad navigation, catalog browsing, search, title details, and video playback.

## Features

- Android TV and Google TV launcher support
- Jetpack Compose for TV with focus and remote navigation
- Home catalog with cinematic featured and continue-watching rows
- Search and title detail screens
- Media3/ExoPlayer playback screen
- Compatible with Android 6.0 (API 23) and newer

## Build

Open the repository in Android Studio or run:

```bash
./gradlew assembleDebug
```

The app uses bundled demo catalog data and a public demo HLS stream, so no API keys or proprietary services are required.
